# CR Open Phase

## Steps

1. Refer to the PB folder's `PB-STATUS.md` and decide which CR to start.
2. ⚠️ **Confirmation required**: Show the CR list from `PB-STATUS.md` and ask:
   "Shall we start CR-XXXX?" — wait for approval before proceeding.
3. Update the CR list in `PB-STATUS.md` and set the CR status to **In Progress**.
4. Create the CR file (e.g. `backlog/PB-0001/CR-01.md`).

## CR-XXXX.md Format

```markdown
# CR-XXXX: Title

## Status: In Progress

## Requirements

## Design

## Development Loop
### [ ] Coding
### [ ] Build  ({{BUILD_COMMAND}})
### [ ] Test   ({{TEST_COMMAND}})

## Completion Checklist
- [ ] Build passes
- [ ] Tests pass
- [ ] Acceptance criteria in BACKLOG.md are satisfied
```
