# prompts/

This directory contains language-neutral CPA development prompt sets.

## Contents

The prompt set provides English, language-neutral guidance for each PB/CR phase:

- `pb_iteration.md` — PB iteration lifecycle guidance
- `pb_open.md` — PB creation phase
- `cr_open.md` — CR creation phase
- `cr_iteration.md` — CR iteration lifecycle guidance
- `cr_requirements.md` — Requirements phase
- `cr_design.md` — Design phase
- `cr_dev_loop.md` — Development loop overview
- `cr_coding.md` — Implementation phase
- `cr_build.md` — Build phase
- `cr_test.md` — Test phase
- `cr_close.md` — CR close phase
- `pb_close.md` — PB close phase

## Usage

These prompts are referenced by `SKILL.md` initialization steps and by
`AGENTS.md` generated from `templates/AGENTS.md` as the shared development
process guide for human-AI collaboration.
